# Kuro Browser Code of Conduct

## Our Commitment

Kuro Browser is an open-source project built by the community.

We want Kuro to be a welcoming, respectful, safe, and productive place for everyone, regardless of their experience level or background.

By participating in the Kuro community, you agree to follow this Code of Conduct.

## Expected Behavior

Community members are expected to:

* Treat everyone with respect.
* Communicate professionally and constructively.
* Welcome new contributors.
* Respect different opinions and perspectives.
* Give helpful and constructive feedback.
* Keep disagreements focused on the work, not the person.
* Respect contributors, maintainers, and community members.
* Give proper credit to other people's work.
* Follow project contribution guidelines.
* Report security issues responsibly.

## Unacceptable Behavior

The following behavior is not permitted:

* Harassment or bullying.
* Discrimination.
* Hate speech.
* Threats or intimidation.
* Personal attacks.
* Sexual harassment or inappropriate sexual content.
* NSFW content in Kuro community spaces.
* Trolling or deliberately disruptive behavior.
* Spam.
* Doxxing or sharing private information.
* Impersonating Kuro contributors or maintainers.
* Malicious code or intentionally harmful contributions.
* Deliberately submitting misleading or disruptive issues or pull requests.
* Repeated bad-faith participation.
* Sharing private conversations or reports without permission.
* Political arguments or political campaigning in official Kuro community spaces.

## Contributions

When contributing code, designs, documentation, or other work, contributors should:

* Follow the project's contribution guidelines.
* Use respectful communication.
* Test changes before submitting pull requests when possible.
* Clearly explain changes in pull requests.
* Respond respectfully to code review feedback.
* Avoid intentionally introducing malicious or harmful changes.
* Respect the decisions of project maintainers.

Technical disagreements are normal. Discuss them constructively and focus on finding a solution.

## Moderation

Kuro maintainers may take action when this Code of Conduct is violated.

Depending on the situation, actions may include:

* A warning.
* Removal of inappropriate content.
* Closing an issue, discussion, or pull request.
* Temporary restrictions.
* Removal from a community space.
* Temporary suspension from contributing.
* Permanent removal from the Kuro community.

Serious or repeated violations may result in stronger action.

Maintainers may also remove spam, malicious content, disruptive contributions, or content that violates project rules.

## Appeals

If you believe moderation action was taken incorrectly, you may appeal the decision through the official Kuro reporting or contact channels.

Appeals should be respectful and provide relevant information about the situation.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, report it to the Kuro project maintainers.

Reports may be submitted through the official Kuro GitHub, Discord, or designated contact method.

Reports will be handled as confidentially as reasonably possible.

Do not publicly share private information about the people involved in a report.

## Scope

This Code of Conduct applies to official Kuro community spaces, including:

* GitHub repositories
* GitHub Issues
* GitHub Discussions
* Pull requests
* Kuro Discord
* Official Kuro community channels
* Other official Kuro project spaces

## Security Reports

Security vulnerabilities should be reported responsibly rather than publicly exploited or used to harm users.

Follow Kuro's security reporting process when one is available.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Enforcement decisions will consider the circumstances and seriousness of the behavior.

The goal of moderation is to keep Kuro's community safe, respectful, and productive.

## Final Note

Kuro is built by people working together.

Be respectful. Help others. Give constructive feedback. Build things together.

**Make Kuro better.**
